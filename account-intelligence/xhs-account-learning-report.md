# 小红书账号学习报告

## 1. 数据来源说明

本报告基于近期账号截图、最近 47 条笔记明细数据、已发布复盘字段，以及当前选题后台中的收藏、待发布、已发布表现记录整理。它不是一次性的运营结论，而是后续 Codex 修改项目、DeepSeek 生成词卡、团队筛选选题时都应优先参考的账号学习资料。

## 2. 账号画像

这个账号不是普通日语词典，也不是单纯搬运日本热词的账号。它更像“小红书中文用户能收藏的日语表达灵感库”。

账号内容应该优先满足：

- 中文用户有共鸣；
- 有明确生活场景；
- 愿意收藏；
- 能做标题和封面；
- 能用轻松可爱的方式讲清楚；
- 风险可控；
- 不像词典和教材。

## 3. 最近数据整体表现

后续判断内容价值时，收藏率比浏览量更重要，互动率比单纯点赞更重要，涨粉效率可以作为辅助判断。浏览高但收藏率低的内容，不应该被强加权。

如果表现差的原因是标题、封面、发布时间、曝光不足，不要过度惩罚词本身。如果表现差的原因是词不适合账号方向，则应降低类似词权重。

## 4. 表现好的内容方向

优先推荐以下方向：

1. 情绪状态词  
   例如：わかりみが深い、ガタが来る、メロい、滅、ぷにっと、ぐうたら、ふて寝、しがみつく、エモ散らかす。

2. 人际关系 / 社交语感词  
   例如：回怼、マウント返し、ズバズバ言う、匂わせ、お手すきない、飯フレ、持って来い、ちょっかいを出す。

3. 生活 / 学习 / 状态场景词  
   例如：一夜漬け、買い出し、買い控え、ソロ活、清水買い、サク飲み、家計簿、時短料理。

4. 可被大众理解的圈层兴趣词  
   例如：ぬい撮り、ライブロス、箱推し、しか勝たん、痛バ。圈层词必须能转译成大众能懂的情绪或场景，不能只面向小圈层。

## 5. 表现弱的内容方向

需要谨慎推荐：

- 纯玩梗词；
- 过度谐音梗；
- 过度圈层词；
- 太基础；
- 太教材；
- 只有浏览高但收藏弱的词；
- 不好配图；
- 不好写标题；
- 词义不稳定；
- 高风险或需复核的词。

## 6. 每日热门选词规则

每日热门不是最终发布池，只是系统推荐。推荐时应优先考虑是否适合中文小红书用户收藏、是否有画面、是否能写成标题、是否适合做图文。

最近 30 天已经出现过的词应优先排除，避免 やばい、推し、映え、草、ガチ 等高分基础词反复回流。候选不足时可以放宽，但需要明确标记。

## 7. DeepSeek 单词卡生成规则

DeepSeek 词卡不是普通词典解释。生成时应：

- 先给场景，再解释词；
- 用中文用户能理解的表达讲清楚；
- 标题有小红书感；
- 封面文案短；
- 例句自然；
- 风险提醒诚实；
- 避免教材口吻；
- 优先服务收藏、发布和图文内容制作。

## 8. 标题生成规则

可优先使用这些标题模式：

- 日本人说「XXX」，其实是在表达这种感觉
- 「XXX」不是 A，而是 B
- 这个日语词，太适合形容我的状态了
- 日语里这种说不上来的感觉，原来可以这样说
- 日本人聊天里常说的「XXX」，到底什么意思？

标题要有场景和情绪，不要像词典词条标题。

## 9. 封面文案规则

封面建议：

- 中文大字 + 日语小字；
- 情绪 / 场景优先；
- 短句优先；
- 不要全日语封面；
- 不要像教材课件。

封面文案应帮助用户一眼判断“这个词和我有什么关系”。

## 10. 发帖文案结构建议

建议结构：

1. 用中文场景开头，引出用户熟悉的情绪或瞬间；
2. 给出日语词和读音；
3. 解释语感，不只翻译；
4. 给自然例句；
5. 给适合使用 / 不适合使用的场景；
6. 用一个轻互动问题结尾。

## 11. 推荐系统加分 / 扣分规则

加分方向：

- 情绪状态词；
- 人际关系 / 社交语感词；
- 生活 / 学习 / 状态场景词；
- 大众可理解的圈层兴趣词；
- 能做标题和封面的词；
- 中文不好直译、有收藏价值的词；
- 能生成自然例句的词。

扣分方向：

- 太基础 / 太教材；
- 过度谐音梗；
- 过度圈层；
- 不好配图；
- 词义不稳定；
- 高风险或需复核；
- 浏览高但收藏弱的历史方向。
