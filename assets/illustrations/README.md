Put the exported illustration PNG files here.

Required filenames:

- `doraemon-propeller.png`: the full-body waving Doraemon with propeller.
- `doraemon-door-bread.png`: Doraemon sitting by the pink door and holding bread.
- `anywhere-door.png`: the standalone pink door.
- `time-machine.png`: the blue clock/time-machine item.
- `memory-bread.png`: the standalone toast slice.
- `propeller.png`: the standalone propeller item.
- `dorayaki.png`: the standalone dorayaki.
- `doraemon-peek.png`: the Doraemon head/peek illustration.

Use transparent PNGs when possible. The page hides missing files automatically, so incomplete assets will not show broken image icons.
