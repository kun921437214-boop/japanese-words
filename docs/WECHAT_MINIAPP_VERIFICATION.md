# 小程序首版验证记录

日期：2026-09-07。全部业务验证使用本地隔离样例，不是 Production 验收。

## 已验证

- 小程序原生五个页面已在微信开发者工具 Stable 2.01.2510290、基础库 3.10.3、iPhone 12/13 (Pro) 模拟器运行。
- Computer Use 实际检查：登录前主按钮禁用、明确进入示例、今日列表、收藏变为“已收进选题池”、选题池由 1 个增加至 2 个、输入“余白”只显示匹配词、详情语感 / 素材切换、复制标题后粘贴回搜索框、标记待发布后列表及详情同步更新。
- 详情滚动到页底时，“下一步”、待发布和移除按钮可见；固定底部按钮避开安全区。无配图示例显示“参考图尚未就绪”，没有伪造图像或保存成功状态。
- 模拟器未出现应用运行错误；工具冷启动较慢，出现平台弃用 / 性能提示，不能据此宣称真机启动性能已经验收。发现 text selectable 弃用提示后改用 user-select，并重新编译。
- 微信 WXML / WXSS 编译器通过全部页面 / 样式文件。
- `npm run test:miniapp`：15 项通过，覆盖成员批准、无公开认证回退、会话过期 / 撤销 / 退出、接口权限、增量写回完整数据、幂等、已发布状态保护、第一方图片读取、限流、超时恢复、重启恢复、跨账号隔离、删除词卡后的缓存失效及正式词卡导出门。
- `npm run lint`、`npm run typecheck`、`npm test`、`npm run build` 均通过；词库构建仍生成 264 个历史种子词及两种输出文件。
- 原网页浏览器回归：`E2E_ROUTE_STATIC=1 node node_modules/@playwright/test/cli.js test --workers=1`，23 项通过，1 项按原条件跳过。第一次普通端口模式中途遇到本机 4174 连接拒绝，已改用仓库原有静态路由模式完成全组测试，未修改生产网络或站点。
- Computer Use 另行在本机示例 HTTP 站点检查原网页的今日、选题池和已发布页面；数据与 Production 隔离。系统候选池、DeepSeek JSON 兼容性和核心 workflow 字段由原测试组覆盖。

## 尚需接入后的验收

- 正式 AppID、微信后台合法域名及隐私说明配置。
- 服务器 AppSecret 和成员编号允许列表；真实 code2Session、自动续期、权限撤销测试。
- iOS / Android 真机的弱网、后台恢复、跨天、字体缩放和相册授权 / 拒绝 / 重试。
- 第一方真实参考图下载与相册落盘；本轮验证的是接口与错误处理，未将示例图片写入用户相册。
- 腾讯网关部署、Nginx 路由接入和微信上传 / 审核 / 发布。

## 生产影响

没有部署腾讯或 Cloudflare，没有修改线上认证、团队数据、环境密钥或同机服务。微信网关默认关闭；Nginx 仅新增待审阅示例文件，未自动加入现有配置。GitHub 提交和 PR 也不代表部署授权。
