# 日语选题 · 微信小程序

原生 WXML / WXSS / JavaScript 小程序，复用已有腾讯团队工作流。它是手机选题入口：今日推荐 → 收藏到选题池 → 查看词卡 → 复制文案 / 保存参考图 → 准备发布。复制、保存、标记待发布都不会自动发布到小红书。

## 先体验

1. 在微信开发者工具中导入本目录。后端服务选“不使用云服务”。
2. `project.config.json` 默认使用占位 `touristappid`；若工具要求有效 AppID，使用工具提供的测试号，或在本机填入你的小程序 AppID。测试号不能代替正式上线。
3. 在登录页选择“先体验交互示例”。每个页面会明确标注示例，示例数据不会连接或写入团队。
4. 依次试用：今日收藏 → 选题池搜索 → 词卡两类内容 → 复制标题 → 待发布标记 → 稍后看和恢复。

交互示例仅用于验证操作，里面的词条、例句和日期都不是正式推荐。新开一次示例会恢复初始示例数据。

## 正式接入

需要你的小程序 AppID、管理员在服务器安全配置 AppSecret、配置合法 HTTPS request / downloadFile 域名，以及审核开通团队成员。具体流程见仓库 `docs/WECHAT_MINIAPP.md`。不要把 AppSecret 发到聊天或放入小程序源码。

前端唯一服务地址在 `config.js`；默认指向 `https://bijinihaitan.cn/miniapp`。后端未启用时，登录明确提示“服务尚未接入”，不会自动切换成示例或公开访问。

## 交互约定

- 底部固定“今日 / 选题池 / 我的”，详情使用微信原生返回。
- 按钮最小点击高度 88rpx，详情底部按钮避开手机安全区。
- 收藏即时在本机显示，服务器回读确认前始终标为“待同步”。多次点击不会生成重复操作。
- 离线时保留上次读取内容；今日快照日期过旧时明确提示，不伪装成当天推荐。
- “稍后看”只影响本机当天的今日列表，可从页底恢复，不写入团队负反馈。
- 搜索支持已加载选题的日语、读音和中文；筛选包括收藏 / 待发布 / 已发布。
- 正式词卡必须为 `aiCard.cardStatus === ready` 且为完整详情，列表投影不能用于复制。
- 未就绪词卡可以收藏，不能复制旧内容或保存旧参考图。
- “我的”显示待同步列表、重试及“以团队最新状态为准”；后者只清除本机意图，不撤销团队已保存操作。
- 缓存按成员隔离；更换微信账号不会把上个成员的待同步队列发送给新账号。
- 相册权限仅在主动保存时申请，拒绝后可以继续浏览。

## 本地验证

在仓库根目录执行 `npm run test:miniapp`。它覆盖身份验证、成员授权、过期 / 退出、最小接口权限、同操作重试、断网恢复、跨账号隔离及正式词卡边界。完整发布前还需要开发者工具、iOS / Android 真机和真实微信登录验收；Node 测试不能证明这些平台能力已经接通。
